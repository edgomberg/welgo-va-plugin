# welgo-va-plugin

Welgo VA plugin. Welgo Brain access scoped to read-and-propose.

## Prereqs

1. Tailscale installed and signed in with your Welgo work email.
2. Ed has shared the Welgo tailnet with you (you accepted his invite link).

## Install

```
claude plugin marketplace add edgomberg/welgo-va-plugin
claude plugin install welgo-va-plugin@welgo-va
```

Restart Claude Code. Plugin auto-downloads the Welgo Brain wrapper on first session. No token paste needed.

## Verify

Ask Claude: "what's in my Welgo task summary?"

If it returns task counts, you are connected.

## Scope

Read VA-SCOPE.md before doing anything. You CAN read canonical data and propose new functionality. You CANNOT edit canonical sources or features.
